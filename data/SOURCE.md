# Data source

All files come from the [`pixarfilms`](https://github.com/erictleung/pixarfilms) dataset by Eric Leung,
released under **CC0 1.0** (public domain dedication), at commit
`e85a10a77b043d45fe8d950dbdf4d27886ccf520` (August 2026).

| File | Contents |
|---|---|
| `pixar_films.csv` | Film number, title, release date, run time, MPAA rating (plot summaries removed) |
| `box_office.csv` | Budget and box office (US/Canada, other, worldwide), USD, not inflation-adjusted |
| `public_response.csv` | Rotten Tomatoes, Metacritic, CinemaScore, IMDb and Letterboxd scores |
| `academy.csv` | Academy Award nominations and wins by category |
| `pixar_franchises.csv` | Which films belong to a franchise |

Box office for 2026 releases reflects the dataset's snapshot and may still be climbing.
This project is not affiliated with or endorsed by Pixar or Disney.
